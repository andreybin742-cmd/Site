# PIXEL HUB

Адаптивный игровой каталог на чистых HTML, CSS и JavaScript.

## Возможности
- Адаптация для телефонов и компьютеров
- Поиск по каталогу и фильтры по жанрам
- Избранное без перезагрузки страницы
- Переключение тёмной и светлой темы
- CSS-иллюстрации и анимированная обложка
- Уважение системной настройки reduced motion

## Публикация через GitHub Pages
1. Откройте **Settings** репозитория.
2. Перейдите в **Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
5. Дождитесь завершения GitHub Actions. Адрес сайта: https://andreybin742-cmd.github.io/Site/

Проект не требует сборки или установки зависимостей.
